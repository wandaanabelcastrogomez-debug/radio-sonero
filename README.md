# Radio Sonero

Radio web con un solo tema: **"El Nazareno"** de Ismael Rivera (Fania Records), que suena completo, de principio a fin (6:06).

## Qué incluye

- Dial de 88 a 108 MHz con una aguja que avanza mientras suena la canción
- Portada del disco y luz de "EN EL AIRE"
- Botón de play/pausa (también con la barra espaciadora)
- Barra de tiempo para adelantar o retroceder
- Control de volumen
- Repetición continua, como una emisora real (se puede apagar)

## Cómo usarla

Abre `index.html` en cualquier navegador y pulsa play. El navegador exige un clic para iniciar el sonido.

No necesita instalación ni servidor. La canción y la portada están incrustadas en el mismo archivo (unos 8 MB), así que funciona sin conexión, salvo las tipografías de Google Fonts.

## Publicar en GitHub Pages

1. Sube `index.html` a la raíz de un repositorio.
2. Ve a **Settings → Pages**.
3. En **Branch** elige `main` y la carpeta `/ (root)`.
4. En un par de minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Derechos de autor

La canción pertenece a Fania Records y a sus titulares. Este proyecto es de uso personal. Si lo publicas en un repositorio abierto, cualquiera podrá descargar el MP3.
